# Dexa attendance design system

Shared by the employee and HR web applications through `@dexa/ui`. The written specification is
`docs/DESIGN.md`; `src/styles/tokens.css` is its executable foundation.

- **Red is the single action color.** State colors always pair with visible text.
- **Open Sans**, 4px spacing scale, rounded cards with smaller control corners, flat surfaces.
- **Accessible by default:** 4.5:1 text contrast, visible focus, 44px targets, reduced-motion support.
- Components accept data, children and callbacks. Applications own API calls, routing and authorization.

Browse **Tokens** for the palette, type and spacing, and **Shared** for components.
